# SimpleDevrei E-commerce Website

A fully functional e-commerce web application built following the SuperSimpleDev tutorial, customized as **SimpleDevrei Ecommerce**. This project simulates a real-world online shopping experience, including interactive product catalogs, cart management, tracking, and order handling.

## 🚀 Live Demo

- **Hosted Site:** [https://simpledevrei-ecommerce.vercel.app](https://simpledevrei-ecommerce.vercel.app)

---

## ✨ Features

- 🛒 **Interactive Shopping Cart:** Add items, adjust quantities, update totals, and delete products seamlessly.
- 📦 **Order Tracking & History:** View past orders and check real-time delivery status for ordered items.
- 🚚 **Dynamic Shipping Options:** Select different delivery speeds with automatically calculated shipping fees and delivery dates.
- 📱 **Responsive Design:** Optimized for smooth browsing across desktop and mobile devices.
- 🔄 **Real-Time Price & Tax Calculation:** Automatic computation of item totals, shipping costs, estimated taxes, and order overall totals.

- **Languages:** HTML5, CSS3, JavaScript (ES6+)
- **Framework:** [React](https://react.dev/)
